# Biome boss geometry prototypes

27 distinct articulated Bedrock/GeckoLib-style `*.geo.json` starting models. Separate head, arm, leg, wing and tail bones support future animation. They have UV coordinates but no finished painted textures, animations, renderer, AI, altar, loot, or spawn registration. These are prototype assets, not production-ready art. See `boss_manifest.json` for the region and identifiers. No changes to worldgen logic.
