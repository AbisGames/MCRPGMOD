## Verified scope

- The server-side entity, encounter, altar, sigil, reward and model-asset bindings are present for all 27 catalog records. `BossDesigns` rejects missing geometry, incomplete animation-state mappings, and unimplemented abilities.
- Each regional boss has a combat GameTest function and an altar/loot GameTest function; Frostbound through Kragmor are also covered by the combined first-boss combat test. The latest complete GameTest run passed all 72 required tests. It includes all boss combat and encounter cases plus the blacksmith profile and set-bonus cases. The unstable mock-player spatial-index setup in several attack tests was corrected by refreshing test-player positions through the server teleport path; the combat assertions remain unchanged.
- A fresh NeoForge 26.1.2 client load completed in the isolated `run-client-regional-qa` profile. After correcting the Tengri/Thalassor crest parent lookups and adding modern item model definitions for the final six boss pairs, the resource reload produced no missing item-model or renderer-construction warnings. The Morvath QA harness was entered, its altar spawned Morvath, and the Regional Blacksmith opened on a Netherite Sword with its Ashlands profile, Cinderite cost, and damage preview correctly localized.
- In the isolated `run-client-regional-qa` world, all 26 non-Morvath entities were spawned in sequence; idle renders and phase-two entry effects were visually inspected, and no model-load or renderer errors appeared. This exposed missing English entity names for Skollvar and Eldaroth (now added); all 27 bosses now have English and Turkish entity-name keys. This pass does not cover full attack/hurt/death sequences or biome-specific swimming and flight animation QA, so `client_qa_complete` remains false.
- The latest full server GameTest run passed all 72 required tests on 2026-10-31; the latest `build` and packaged-JAR validator also passed. The validator checks all 27 boss model links and both modern item definitions per boss, in addition to textures, recipes, profiles, and absence of GameTest content in the distributable JAR.
