# Exceptional fantasy biome terrain

Aetheris Expanse is sampled in the high air (Y>250) above selected Greyspine areas.
The regional density function now adds isolated suspended island density around Y=317 where the biome chooser selects Aetheris. The vanilla noise router is preserved for other locations.
Verdant Depths is confined to jungle underground positions (Y<44), using the Minecraft 26.1 lush-caves feature and carver settings.
Umbral Chasm is an underground Greyspine biome with the 26.1 deep-dark feature set.
The reef/volcanic fantasy overlays remain part of the RPG biome source.

Sky island generation is experimental; not yet calibrated in a new singleplayer save, and actual float/height/spacing needs visual verification.
