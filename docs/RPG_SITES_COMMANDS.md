# Singleplayer site locator

In a Pipican RPG World save, enter:

/rpgsites
/rpgsites locate sylvaran
/rpgsites locate durnhold
/rpgsites progress

The nearest command prints eight authored settlement coordinates.
Locate accepts any of the 70 settlement IDs with Brigadier suggestions.
Progress reports finished placed landmark counts (22 capitals contain 63
construction stages, other sites one). These commands do not spawn,
teleport, regenerate or overwrite blocks. They work with the in-game save
and help manual architecture/exploration QA.

Do not use region coordinates to infer a fixed Y: the on-demand placement
system samples local terrain.
