# Full authored structure kits

The old claim that the mod only has six small NBT prototypes is obsolete.
The generator in tools/worldgen/build_full_structures.py creates 967 distinct modular architectural NBT templates:
923 original authored templates plus 44 new culturally themed inter-district walkway templates.
Six very early 21x16x21 shells remain separately in the repository, outside the 967 generated assets.
All 331 original authored pool IDs are represented. Twenty-two capital complexes each use 25 main tile placements and 38 pedestrian connectors.
Models have multiple floors, decorated interiors, doorways, thematic materials, roofs and functional traversal structures.
Twenty-seven mine models expose special RPG nodes, and twenty-seven dungeon models have trial arenas with loot.
All 70 named settlements can be built from the in-game incremental placement service.

These assets are procedural and reusable; detailed visual accuracy against concept artwork remains untested.
Code compilation and template validation are not a substitute for walking all structures in singleplayer.
