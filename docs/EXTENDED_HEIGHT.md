# RPG Overworld height

The custom RPG world preset uses min_y=-64, height=576 and logical_height=576, making Y=-64..511 available.
Vanilla Overworld worlds are unaffected.
Castle foundations use sampled terrain height, not an assumed Y=70.
Regional density emphasizes mountainous territories, but does not provide hand-designed multi-kiloblock castle valleys or floating islands yet.
New save creation is required for dependable dimension-height changes.
