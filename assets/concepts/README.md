# Pixel art and NPC visual direction

The PNG icon resources in `src/main/resources/assets/pipican/textures/gui/` are real 16x16 RGBA images. They are placeholders, not polished NPC skins.

A concept sheet was produced as a design reference in the ChatGPT conversation. It is NOT a runtime game texture, nor a UV-mapped NPC model.

Art direction: original pixel-art NPC professions (trainer, dojo master, miner, blacksmith, witch, cook, alchemist, merchant); opaque Minecraft UI font, dark translucent screens over the real world. Do not include class names or class-specific NPC character designs until classes are finalized.
